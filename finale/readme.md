# Compte rendu finale (résumé du TP)

Ce dossier est rendu à la fin du projet de ML sur la classification des races de chiens. il est structuré comme suit : 
* Le dossier **code** contient les notebooks utilisés dns le processus de modélisation (EDA, Préprocessing, modélisation).
* le dossier **output** contient : les fichiers de processing pour 10 races et pour tous les races (processor_object_full et processor_object_sample); les dossiers data_test et data_train qui contiennent des générateurs de données train et test pour toutes les races et pour 10 races; un dossier train_models qui contient les modeles entrainés.
* le dossier **API** qui contient le code de l'api et les requirements. 
* le dossier **src** qui contient les fonctions utilitaires utilisées
